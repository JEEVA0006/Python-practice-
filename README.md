Python Practice Programs 

Welcome to my Python practice repository!

This repository contains four Python programs I created while learning Python and improving my problem-solving skills.

 Programs

1. Palindrome Checker

Checks whether an integer reads the same forward and backward.

2. Power of Two

Checks whether a number is a power of two.

3. Number of Steps to Zero

Counts the steps required to reduce a number to zero using specified operations.

4. Rome Overlap Days

Calculates the number of days Alice and Bob are in Rome at the same time.

 Goal

To practice Python programming, improve logical thinking, and document my coding journey.
